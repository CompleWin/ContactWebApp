# ContactWebApp

CRUD веб-приложение для управления списком контактов.

## Основные возможности

- **Create**: Добавление нового контакта в базу данных
<img width="1477" height="494" alt="image" src="https://github.com/user-attachments/assets/8925cc1c-4dfd-457b-8418-e5298ab2b621" />

- **Read**: Просмотр всех контактов в базе
<img width="1467" height="842" alt="image" src="https://github.com/user-attachments/assets/0f63dbe6-907f-402e-9d95-a6a88f3a3305" />

- **Update**: Обновление всех данных контакта в базе
- **Delete**: Удаление контакта из базы

<img width="1436" height="403" alt="image" src="https://github.com/user-attachments/assets/cbfe0548-fb2c-4a4f-bf60-70a762445735" />

- **Pagination**: Пагинация

## Стек технологий

Проект построен с использованием следующих инструментов:

* **Backend:** ASP.NET Core (.NET 9)
* **Database:** Entity Framework Core (PostgreSQL)
* **Frontend:** React
* **UI/UX:** Bootstrap
* **API:** RESTful API
